QuickNotes

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS, and JavaScript. It allows users to create and organize notes into Personal, Work, and Study categories, search for notes, and delete notes they no longer need. Notes are saved in the browser's local storage, so they remain available after refreshing the page.

Features

- Add notes: Create notes with text and a selected category.
- Categories: Organize notes into Personal, Work, and Study.
- Validation: Prevent empty notes and notes longer than 200 characters.
- Delete notes: Remove individual notes when they are no longer needed.
- Live search: Find notes using case-insensitive text matching.
- Note counter: Display the total number of notes.
- Local storage: Keep notes saved across page refreshes.
- Responsive design: Use the application on desktop and mobile screens.
- Timestamps: Display the date and time each note was created.

Technologies Used

- HTML5

How to Run Locally

1. Clone this repository:
   
   git clone https://github.com/mark-ochieng/quicknotes-app.git

2. Open the project folder:
   
   cd quicknotes-app

3. Open "index.html" in your web browser, or use the Live Server extension in Visual Studio Code.

No additional packages or installation are required.
